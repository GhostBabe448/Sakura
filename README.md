
# Sakura Motors - Concesionario de Coches Japoneses

Web estatica de venta de coches japoneses premium desarrollada con HTML, CSS y JavaScript vanilla. Lista para desplegar en GitHub Pages.

---

## 1. Que hace la web

Sakura Motors es una pagina web de concesionario especializado en vehiculos japoneses de alta gama. Incluye:

- **Catalogo de vehiculos**: 12 coches japoneses reales (Toyota, Honda, Nissan, Mazda, Subaru, Lexus) con fotos, especificaciones y precios.
- **Filtro por marca**: Filtra rapidamente los coches por fabricante.
- **Detalle de vehiculo**: Modal con informacion completa del coche seleccionado.
- **Chat con vendedor**: Sistema de chat ficticio con respuestas automaticas sobre precio, financiacion, garantia y mas.
- **Registro e inicio de sesion**: Sistema completo de autenticacion usando localStorage.
- **Diseño responsive**: Adaptado para movil, tablet y escritorio.
- **Animaciones suaves**: Transiciones y efectos visuales profesionales.
